# القرارات: المعرض الذكي

هنا كل القرارات اللي اتخذناها بالمشروع: شنو القرار، وليش، وبياهو PR تنفّذ.

**إذا تعارض شي بهالملف وية ملف ثاني أو وية محادثة قديمة، القرار الأحدث هنا هو الصح.**

**شلون يتحدّث:**
- كل قرار جديد ينضاف بالقسم المناسب، وبنفس الـ PR اللي ينفّذه.
- إذا قرار جديد لغى قرار قديم، القديم ينتقل لقسم «قرارات انلغت» وينكتب شنو اللي بدّله.
- القرارات اللي تصير بمحادثات مشروع Claude على claude.ai: الصقها بجلسة Claude Code حتى تنضاف هنا.

آخر تحديث: 11 تشرين الثاني 2026
