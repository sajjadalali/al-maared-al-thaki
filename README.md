# المعرض الذكي — Smart Dealership

منصة Demo لمعرض سيارات ذكي في العراق، مبنية بـ Next.js (App Router) و TypeScript
و Tailwind CSS. تعرض سيارات تجريبية، بحث وتصفية، صفحة تفاصيل لكل سيارة، ومساعد
ذكاء اصطناعي باسم **سديم** يتحدث بلهجة عراقية ويساعد الزائر على اختيار السيارة
المناسبة من بيانات الموقع الفعلية.

## التشغيل محلياً

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

## بيانات المعرض والتواصل

اسم المعرض، رقم الهاتف، رقم الواتساب، البريد، العنوان، أوقات العمل وروابط التواصل
الاجتماعي كلها في ملف واحد: `src/config/site.ts`. عدّلها هناك وتتحدث في كل الصفحات
وفي ردود سديم وأزرار الواتساب.

## تحديث السيارات من ملف الإكسل

مصدر بيانات السيارات هو الملف `content/cars.xlsx` (ورقة «السيارات»، كل صف = سيارة،
والقيم الثابتة تُختار من قوائم منسدلة؛ التعليمات الكاملة في ورقة «طريقة الاستخدام»).
بعد تعديله شغّل:

```bash
npm run import-cars        # على ويندوز PowerShell: npm.cmd run import-cars
```

السكربت يتحقق من كل صف؛ إذا وجد خطأ يطبع رقم الصف والعمود ولا يغيّر شيئاً، وإذا كانت
البيانات سليمة يكتب `src/data/cars.json` الذي يقرأ منه الموقع.

إضافة للأعمدة الأساسية، كل سيارة تقبل أعمدة اختيارية تظهر في صفحتها وفي ردود سديم:
**الفئة** (GXR، SE...)، **الوارد** (وكالة، خليجي، أمريكي، كوري...)، **السلندر**،
**القوة (حصان)** و**نظام الدفع** (أمامي، خلفي، رباعي، كلي). عمود «الوارد» يظهر أيضاً كفلتر
في صفحة السيارات، وسديم يفهمه («عندكم لاندكروزر خليجي؟»).

البحث في صفحة السيارات وسديم يفهمان الأسماء كما يكتبها الزبون بالعربي («لاندكروزر»، «هايلوكس»،
«بي ام دبليو X5»، «صينية»، «بيك اب»). التهجئات في `src/lib/carAliases.ts`: أضف أي اسم أو موديل
جديد هناك مرة واحدة فيعمل في الاثنين.

> السيارات الحالية في الملف نسخة عرض: الموديلات والمواصفات والتجهيزات حقيقية لكل سيارة،
> والأسعار مأخوذة من إعلانات السوق العراقي (انظر القسم التالي)، لكنها ليست مخزون معرض فعلي —
> استبدلها بسيارات المعرض الحقيقية.

## أسعار السوق والصور

ملف `content/research/cars-research-2026-10.xlsx` يجمع بحث تشرين الأول 2026 للسيارات
الـ 34:

- **الأسعار**: وسيط أسعار الطلب في إعلانات carzonee.iq و iqcars.net لكل موديل وسنة، مع أقل
  وأعلى سعر وروابط الإعلانات، والسعر المقترح بالدينار (وهو المطبّق الآن في `cars.xlsx`).
  السيارات الجديدة التي لا إعلانات لها بالعراق (أغلب الصينية، GLE، سنتافي 2026، EV6) مسعّرة
  من أسعار الوكلاء بالسعودية والإمارات ومكتوب عليها «تقدير» — أكّدها من الوكيل.
- **سعر الصرف**: الأسعار محسوبة على سعر السوق (1,685 دينار للدولار، بورصة الكفاح 24/10/2026)
  لا السعر الرسمي (1,510)، وهو نفس الرقم الذي يعرض به الموقع السعر التقريبي بالدولار
  (`USD_TO_IQD` في `src/lib/format.ts`). حدّثه عند تغيّر السوق.
- **الصور**: 91 صورة حقيقية لنفس الموديلات من ويكيميديا كومنز برخص تسمح بالاستخدام مع ذكر
  المصوّر، روجعت واحدة واحدة (الصورة الأولى لكل سيارة هي الأوضح، ولون السيارة بالملف يطابقها).
  صور مواقع الإعلانات والصور الصحفية للشركات محمية بحقوق ولا تُستخدم.

الصور موجودة في `public/cars/`. عند تعديل ورقة «الصور» في ملف البحث ودفعه إلى GitHub، يشغّل
workflow ‏«Fetch car photos» (`.github/workflows/fetch-photos.yml`) التحميل تلقائياً ويرفع
الصور الجديدة. ويمكن تشغيله محلياً (يحتاج إنترنت يصل إلى wikimedia.org):

```bash
npm run fetch-photos       # على ويندوز: npm.cmd run fetch-photos
npm run import-cars
```

`fetch-photos` يحمّل الصور من ورقة «الصور» في ملف البحث إلى `public/cars/` بصيغة webp، ويضيف
أسماءها لعمود «الصور» في `cars.xlsx` بعد صور المعرض الخاصة إن وُجدت، ويحفظ الإسناد في
`src/data/image-credits.json`. الموقع يعرض الإسناد تحت الصورة في صفحة السيارة وفي صفحة
«حقوق الصور» (`/credits`). الصور الموجودة مسبقاً لا يعاد تحميلها (لإعادة تحميلها: `npm run fetch-photos -- --force`)،
ولحذف صورة احذف صفها من ورقة «الصور» وأعد التشغيل.

## استبدال مصدر البيانات لاحقاً

- **السيارات**: يمكن تبديل `src/data/cars.ts` بطبقة تقرأ من Supabase/API مع إبقاء نفس التوابع
  (`getAllCars`, `getCarById`, `filterCars`...) حتى لا تحتاج لتعديل أي Component.
- **الصور**: ضع صور السيارات في `public/cars/` واكتب أسماءها في عمود «الصور» في ملف
  الإكسل (مثل `toyota-camry-2024-1.webp`؛ أول صورة تظهر في البطاقة). إذا كانت الصورة غير
  موجودة أو العمود فارغاً، يعرض الموقع رسماً للسيارة بشكل هيكلها (سيدان، SUV، دفع رباعي،
  بيك أب...) وبلونها الحقيقي، مع ملاحظة «صورة توضيحية» في صفحة السيارة.
- **الذكاء الاصطناعي**: سديم مربوط بنموذج لغوي عبر OpenRouter وقاعدة Supabase (القسم التالي).

## سديم الذكي: Supabase + OpenRouter

سديم يعمل بنموذج لغوي (عبر OpenRouter) يبحث في سيارات المعرض المخزّنة في Supabase. كل
رد يمرّ هكذا:

1. المتصفح يرسل الرسالة وآخر المحادثة إلى `/api/chat` (`src/app/api/chat/route.ts`).
2. الخادم يرسلها للنموذج مع تعليمات سديم (`src/server/sadeem/prompt.ts`): اللهجة العراقية،
   «دفتر» و«ورقة» والميزانية بالدينار والدولار، وقائمة الماركات والموديلات المتوفرة الآن.
3. النموذج يستدعي أدوات (`src/server/sadeem/tools.ts`): `search_cars` (فلاتر دقيقة + بحث نصي
   يتحمّل الأخطاء الإملائية)، `get_car_details`، `show_cars` (يعرض بطاقات السيارات، ولا يقبل إلا
   سيارات رجعت من البحث فعلاً)، `save_lead` (يحفظ رقم الزبون)، `suggest_replies`.
4. الرد يرجع للمحادثة مع بطاقات السيارات وأزرار واتساب والاتصال.

إذا لم تكن المفاتيح مضبوطة، أو تعطّل OpenRouter، يرد سديم القديم (`mockAI.ts`) تلقائياً.

### قاعدة البيانات

`supabase/migrations/20261026000000_catalog.sql` ينشئ الجداول: `brands` ← `models` ← `cars`
مع `car_images` (المسار والإسناد) و`features` عبر `car_features`، و`leads` (أرقام الزبائن)
و`chat_sessions`/`chat_messages` (المحادثات، لتحسين سديم)، والدالتين `search_cars()` و
`catalog_overview()` والعرض `cars_full`. الكتالوج قابل للقراءة للجميع، والزبائن والمحادثات
محمية (RLS) ولا يكتبها إلا الخادم بالمفتاح السري.

للإنشاء من الصفر: افتح SQL Editor في Supabase وشغّل ملف الـ migration ثم `supabase/seed.sql`
(السيارات الـ 34 بكل تفاصيلها وتجهيزاتها وصورها).

بعد تعديل الإكسل و`npm run import-cars`، انقل التغييرات إلى Supabase:

```bash
npm run sync-supabase                    # يحتاج SUPABASE_URL و SUPABASE_SECRET_KEY
npm run sync-supabase -- --sql supabase/seed.sql   # أو اكتبها كملف SQL
```

### متغيرات البيئة (في Coolify ← Environment Variables)

| المتغير | القيمة |
|---|---|
| `OPENROUTER_API_KEY` | مفتاح OpenRouter |
| `OPENROUTER_MODEL` | اختياري، الافتراضي `anthropic/claude-haiku-5.5` (سريع ورخيص)؛ `anthropic/claude-sonnet-5.5` أذكى وأبطأ. أي نموذج يدعم tools |
| `OPENROUTER_REASONING_EFFORT` | اختياري، الافتراضي `low` (رد أسرع)؛ `medium` أو `high` لتفكير أعمق |
| `SUPABASE_URL` | `https://<project>.supabase.co` |
| `SUPABASE_PUBLISHABLE_KEY` | المفتاح العام (`sb_publishable_...`) لقراءة الكتالوج |
| `SUPABASE_SECRET_KEY` | المفتاح السري (`sb_secret_...`) لحفظ الأرقام والمحادثات؛ لا يوضع أبداً في الواجهة |

كل المفاتيح تُقرأ في الخادم فقط. لكل زائر حد 30 رسالة كل 10 دقائق.
