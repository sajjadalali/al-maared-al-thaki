# المعرض الذكي — Smart Dealership

منصة Demo لمعرض سيارات ذكي في العراق، مبنية بـ Next.js (App Router) و TypeScript
و Tailwind CSS. تعرض سيارات تجريبية، بحث وتصفية، صفحة تفاصيل لكل سيارة، ومساعد
ذكاء اصطناعي باسم **سديم** يتحدث بلهجة عراقية ويساعد الزائر على اختيار السيارة
المناسبة من بيانات الموقع الفعلية.

## التشغيل محلياً

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

## البنية

```
src/
  app/                 صفحات Next.js (الرئيسية، السيارات، تفاصيل السيارة، المفضلة...)
  components/
    cars/              بطاقة السيارة، الفلاتر، البحث، المعرض، المواصفات...
    chat/              واجهة محادثة سديم (فقاعات، بطاقات سيارات، اقتراحات سريعة...)
    layout/            الهيدر والفوتر
    ui/                مكونات عامة (صورة السيارة مع fallback، أيقونات...)
  context/             FavoritesContext (المفضلة عبر localStorage)
  data/
    cars.json           بيانات السيارات التجريبية
    cars.ts              طبقة الوصول للبيانات (getAllCars, filterCars, searchCars...)
  services/ai/          طبقة الذكاء الاصطناعي القابلة للاستبدال
    mockAI.ts            المحرك الحالي: يحلل الرسالة ويبحث في cars.json
    index.ts             نقطة الدخول الموحدة (aiService) التي تستخدمها الواجهة
  lib/                  أدوات مشتركة: formatIQD, cn, filterOptions...
public/cars/            مكان صور السيارات الحقيقية لاحقاً (بصيغة webp)
```

## بيانات المعرض والتواصل

اسم المعرض، رقم الهاتف، رقم الواتساب، البريد، العنوان، أوقات العمل وروابط التواصل
الاجتماعي كلها في ملف واحد: `src/config/site.ts`. عدّلها هناك وتتحدث في كل الصفحات
وفي ردود سديم وأزرار الواتساب.

## تحديث السيارات من ملف الإكسل

مصدر بيانات السيارات هو الملف `content/cars.xlsx` (ورقة «السيارات»، كل صف = سيارة،
والقيم الثابتة تُختار من قوائم منسدلة؛ التعليمات الكاملة في ورقة «طريقة الاستخدام»).
بعد تعديله شغّل:

```bash
npm run import-cars        # على ويندوز PowerShell: npm.cmd run import-cars
```

السكربت يتحقق من كل صف؛ إذا وجد خطأ يطبع رقم الصف والعمود ولا يغيّر شيئاً، وإذا كانت
البيانات سليمة يكتب `src/data/cars.json` الذي يقرأ منه الموقع.

> الأسعار الحالية في الملف تقديرية مبنية على إعلانات السوق العراقي (2026) لتشغيل الـ
> Demo، وليست مخزون معرض فعلي — استبدلها بسيارات المعرض الحقيقية.

## استبدال مصدر البيانات لاحقاً

- **السيارات**: يمكن تبديل `src/data/cars.ts` بطبقة تقرأ من Supabase/API مع إبقاء نفس التوابع
  (`getAllCars`, `getCarById`, `filterCars`...) حتى لا تحتاج لتعديل أي Component.
- **الصور**: ضع صور السيارات في `public/cars/` وأشر لها من حقل `images` في
  `cars.json` (مثل `/cars/toyota-camry-2024-1.webp`). إذا كانت الصورة غير موجودة
  أو الحقل فارغاً، يعرض الموقع بديلاً مصمماً بدل صورة مكسورة.
- **الذكاء الاصطناعي**: لربط سديم بنموذج حقيقي، أنشئ ملف يطبّق واجهة `AIService`
  (انظر `src/services/ai/types.ts`) ويستدعي الـ API الخاص بك من طرف الخادم (لا
  تضع مفاتيح API في الواجهة الأمامية)، ثم بدّل التصدير في `src/services/ai/index.ts`.
  واجهة المحادثة نفسها لا تحتاج أي تعديل.
